# 🐰 초3 국어 낱말 탐험대 (3분 스피드 챌린지)

초등학교 3학년 1학기 국어 교과서 연계 5단계 레벨업 낱말 맞추기 게임 웹 애플리케이션입니다.

---

## 🌟 주요 특징

1. **초등 3학년 1학기 국어과 교육과정 5단계 연계**
   - **🌱 1단계 (새싹 어휘 탐험대)**: 1단원 *재미가 톡톡톡* (감각적 표현 & 흉내 내는 말: 새근새근, 알록달록, 살랑살랑 등)
   - **🎀 2단계 (예절 쑥쑥 높임말 마스터)**: 3단원 *알맞은 높임 표현* (진지, 성함, 편찮으시다, 댁, 여쭙다)
   - **🔍 3단계 (알쏭달쏭 낱말 탐정)**: 7단원 *반갑다 국어사전* & 2단원 *문단의 짜임* (국어사전 자음 순서, 기본형, 반대말·비슷한 말, 사전적 뜻풀이)
   - **💡 4단계 (생각 탄탄 문장 완성)**: 6단원 *일이 일어난 까닭* & 8단원 *의견이 있어요* (원인과 결과 접속어, 까닭, 제안하는 글)
   - **👑 5단계 (국어 왕관의 주인공)**: 4단원 *마음을 편지에 담아* & 9·10단원 *문학의 향기* (마음 표현 어휘 및 관용 표현)

2. **게임학습(Gamification) 요소**
   - **3분 타임어택 (180초)**: 박진감 넘치는 시간제한으로 지루함 없이 빠른 반복 학습 가능
   - **3개의 하트 라이프 (목숨)**: 오답 시 하트 소모 및 격려 피드백
   - **연속 콤보 & 🔥 피버 모드**: 연속 3문제 정답 시 점수 2배 획득
   - **3가지 찬스/힌트 시스템**:
     - 💡 초성 힌트 (자음 초성 보기)
     - 📖 국어사전 뜻풀이 찬스
     - ✂️ 50:50 보기 지우기 찬스
   - **🔊 선생님 목소리로 듣기 (TTS)**: Web Speech API 기반 문제 및 문장 낭독 지원
   - **📚 낱말 복습노트 (오답노트)**: 틀린 문제와 맞힌 문제의 사전적 뜻풀이 및 상세 해설 제공

3. **학습자 인증 및 맞춤화**
   - 탐험가 별명 입력 및 추천 별명 주사위 기능
   - 입장 비밀번호 `2026` 확인

## 🚀 시작하기 (Getting Started)

### 설치 (Installation)

```bash
npm install
```

### 개발 서버 실행 (Development)

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`으로 접속하여 실행합니다.

### 빌드 (Production Build)

```bash
npm run build
```

---

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS v4
- **Animation**: Motion, canvas-confetti
- **Audio Engine**: Web Audio API (외부 오디오 파일 없이 무지연 브라우저 합성 사운드)
- **Speech**: Web Speech API (TTS)
- **Icons**: Lucide React
